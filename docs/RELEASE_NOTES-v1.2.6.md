# 音签 MusicTagger v1.2.6

细节修复版本：**设置项间距对齐、Tab 滑动去分割线**。

## 下载

- `MusicTagger-v1.2.6.apk`（R8 压缩 + 资源裁剪，约 **1.5 MB**）
- 校验：`SHA256.txt` 与 APK 一同发布（SHA-256：`AF9B5F217AEEF4600351CAE5103734272A9845363D67D1EFF85CCF6F09D50039`）
- 系统要求：Android 8.0（API 26）及以上；动态取色需 Android 12+

## 更新内容

- **设置项间距统一**：关于音签、音频参数、文件、封面与歌词等条目统一使用 16dp 左右、
  16dp 上下内边距，与「默认搜索平台」的卡片留白一致，不再贴住白色圆角矩形的上下边缘。
- **分段 Tab 动画修复**：白色滑块滑动时的“分割直线”来自各选项卡点击区域自带的矩形按压高亮；
  现已移除 Tab 点击区的 indication，只保留滑块本体。滑块改为胶囊形，并在滑动过程中
  略微收窄为小胶囊，移动到目标后再展开，避免边缘扫过相邻选项边界，整体更干净优雅。
- 其余功能与 v1.2.5 一致。

## 验证

- release APK 在 API 36 模拟器安装：设置/关于/文件信息间距正常；Tab 切换动画无矩形高亮残影；
  154 个 `:core` 单测通过。

## 已知限制

- Spotify 源未接入（OAuth + 无歌词接口）。
- release 目前使用 debug 签名，便于直接安装。
