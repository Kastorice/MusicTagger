# 音签 MusicTagger v1.2.2

细节与信息完善版本：**中性无阴影 Tab、歌曲信息页搜索 FAB、更完整的文件信息**。

## 下载

- `MusicTagger-v1.2.2.apk`（R8 压缩 + 资源裁剪，约 **1.5 MB**）
- 校验：`SHA256.txt` 与 APK 一同发布（SHA-256：`2B098161BCCD13884D96E6F7600F41393FE733C303D82611D86C346CC14AC5D5`）
- 系统要求：Android 8.0（API 26）及以上；动态取色需 Android 12+

## 更新内容

- **分段控件去除阴影**：只保留灰轨道 + 白色滑块，切换时仍有 220ms 位移动画。
- **歌曲信息页**：移除卡片内的「在线匹配所有歌曲信息」大按钮，改为与歌词页一致的
  圆形悬浮搜索 FAB（白底黑图标、与保存 FAB 同款阴影，保存按钮左侧）；
  仅「文件信息」Tab 不显示该 FAB。
- **文件信息更完整**（仍保持 1.5 MB 体积，无新增依赖）：
  - 格式、扩展名、时长、时长（毫秒）
  - 大小、大小（字节）、比特率、采样率、声道、位深
  - 编码、MIME 类型
  - 封面是否存在、封面尺寸、封面格式、封面大小
  - 歌词行数、歌词字符数、已填标签字段数（/9）、标签字符数
  - 文件名、SAF 文件位置、最后修改时间
- 读取文件最后修改时间（SAF `last_modified`）、编码与位深（MediaExtractor）、封面尺寸（仅解码边界）。

## 验证

- release APK 在 API 36 模拟器安装，歌曲信息/歌词/文件信息三个 Tab、搜索 FAB、文件信息各字段正常；
- 154 个 `:core` 单元测试保持通过。

## 已知限制

- 位深/编码等字段由系统 MediaExtractor 提供，个别容器可能返回“未知”。
- Spotify 源仍未接入（OAuth + 无歌词接口）。
- release 目前使用 debug 签名，便于直接安装。
