# 音签 MusicTagger v1.2.3

体验修复版本：**打开匹配即自动搜索、文件信息精选、播放按钮修复**。

## 下载

- `MusicTagger-v1.2.3.apk`（R8 压缩 + 资源裁剪，约 **1.5 MB**）
- 校验：`SHA256.txt` 与 APK 一同发布（SHA-256：`E17B26B2225F3BD5DE79B7EF6F1577741F62087D96F841EDD3B6B66C52882B74`）
- 系统要求：Android 8.0（API 26）及以上；动态取色需 Android 12+

## 更新内容

- **打开即搜索**：点击右下角圆形搜索 FAB（或封面卡片的匹配入口）后，自动用当前
  「歌曲名 / 歌手」关键词发起搜索并直接展示结果，无需再手动点「搜索」。
  仍可修改关键词后手动重新搜索，或切换数据源自动重搜。
- **文件信息更聚焦**：去掉扩展名、毫秒、精确字节、MIME、标签字段统计等冗余项，
  按三组呈现，既精简又有细节：
  - 音频参数：格式、时长、比特率、采样率、声道、位深、编码
  - 文件：大小、文件名、文件位置、最后修改
  - 封面与歌词：封面、封面尺寸、封面格式、封面大小、歌词行数
- **播放按钮修复**：曲库卡片的播放按钮不再把「音签」自己放进打开方式候选，
  避免 ACTION_VIEW 默认落到本应用而跳进编辑页；现在会直接调起外部播放器
  （或用系统选择器选择其它应用）。

## 验证

- release APK 在 API 36 模拟器安装：搜索 FAB 打开后自动出现结果；
  播放按钮直接打开 YouTube Music；文件信息三组字段显示正常。
- 154 个 `:core` 单元测试保持通过；APK 体积仍约 1.5 MB。

## 已知限制

- 位深/编码等由系统 MediaExtractor 提供，个别容器可能返回“未知”。
- Spotify 源未接入（OAuth + 无歌词接口）。
- release 目前使用 debug 签名，便于直接安装。
