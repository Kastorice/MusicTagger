# 音签 MusicTagger v1.2.5

导航与细节优化版本：**预见性返回、Tab 横滑、精简封面弹窗与设置**。

## 下载

- `MusicTagger-v1.2.5.apk`（R8 压缩 + 资源裁剪，约 **1.5 MB**）
- 校验：`SHA256.txt` 与 APK 一同发布（SHA-256：`9BB7A45CB0391847A1BD07C33B8B41B213A1CAE22827F0DF6D52C98EABC3ABA2`）
- 系统要求：Android 8.0（API 26）及以上；动态取色需 Android 12+

## 更新内容

- **封面替换弹窗**：首项改为「在线匹配专辑封面」，删除所有灰色说明文字与分割线。
- **曲库 / 设置切换**：去掉 Crossfade 模糊渐变，改为左右横向滑动（280ms、标准缓动，
  随切换方向反向滑动）。
- **预见性返回**：编辑页使用 `PredictiveBackHandler`，返回手势进行中编辑页跟随手指右移，
  取消回弹、完成关闭；有未保存修改时仍弹出确认对话框。
- **返回层级**：设置页按返回回到曲库；曲库搜索有内容时按返回清空搜索回到主页，而不是退出应用。
- **文件信息**：条目改为 16dp 左右内边距、8dp 行距，与白色卡片边缘/上下间距对齐更自然。
- **曲库搜索框**：移除右侧「取消」按钮，只保留输入框内清除按钮；返回键负责退出搜索。
- **设置 · 在线数据源**：删除网易云 API 地址输入框及说明；改为「当前值 + 箭头」的下拉选择器，点击展开列表直接选择网易云 / QQ 音乐（当前项带对勾）。

## 验证

- release APK 在 API 36 模拟器安装：设置返回回到曲库、搜索返回清空、封面弹窗/文件信息/设置
  新布局均正常；预测返回手势可关闭编辑页；154 个 `:core` 单测通过。
