# 音签 MusicTagger v1.2.7

间距与 Tab 细节修正：**卡片留白与行距平衡、白色滑块圆角贴合边框**。

## 下载

- `MusicTagger-v1.2.7.apk`（R8 压缩 + 资源裁剪，约 **1.5 MB**）
- 校验：`SHA256.txt` 与 APK 一同发布（SHA-256：`D83163DEF102CA7B00CB69744EFD4CF050DA44A4BE7F17BA7CF3A0186FA4C9AB`）
- 系统要求：Android 8.0（API 26）及以上；动态取色需 Android 12+

## 更新内容

- **设置项间距重新平衡**：卡片内的第一/最后一行仍保持接近「默认搜索平台」的上下留白（约 16dp），
  但行与行之间的间距收窄到约 20dp，不再出现过大的空隙。
- **下拉选择器**：在线数据源行与菜单选项同步收窄上下内边距，选项之间更紧凑。
- **分段 Tab 选中态**：白色滑块恢复为 9dp 圆角矩形（与灰色轨道 12dp 外圆角、3dp 内缩后的
  内圆角完全一致），不再使用二分之一圆，达到贴合效果。
- 滑块滑动仍使用弹性动画；点击区不显示矩形按压高亮，避免分割线残影。

## 验证

- release APK 在 API 36 模拟器安装：设置/关于/文件信息行距正常，白块圆角与轨道边框贴合；
  Tab 切换动画无高亮残影；154 个 `:core` 单测通过。

## 已知限制

- Spotify 源未接入（OAuth + 无歌词接口）。
- release 目前使用 debug 签名，便于直接安装。
